# Módulo 06 — Claude Code

**Eje:** Desarrollador
**Tiempo estimado:** 8–12 h
**Prerrequisitos:** Módulo 05. Conocimientos básicos de terminal y Git.
**Última actualización:** 2026-04-23

## Objetivo

Dominar Claude Code como herramienta de desarrollo: instalación, configuración, `CLAUDE.md`, comandos personalizados, hooks, plan mode, y la integración con tu entorno real de trabajo (GitHub, IDE, terminal).

## Recursos clave

Del catálogo:
- `claude-code-in-action` ⭐ (curso oficial, con subtítulos en español).
- `docs-claude` — sección Claude Code de la documentación.
- `claude-code-sdk-python` — SDK oficial.
- `claude-plugins-official` — plugins oficiales.
- `awesome-claude-code` — lista curada de tools comunidad.
- `midudev` — tutoriales prácticos en español.

## Entrega

Configura un proyecto real tuyo con un `CLAUDE.md` propio (distinto al de este curso), al menos 2 comandos slash personalizados y 1 hook útil. Documenta en `modulos/06-claude-code/mi-configuracion.md` tu decisión arquitectónica y qué has aprendido al configurarlo.
