# Integración con VS Code y JetBrains

## Objetivos de aprendizaje

Al terminar esta lección serás capaz de:

- [ ] Explicar qué aporta usar Claude Code **dentro del IDE** frente a la terminal.
- [ ] Conocer las integraciones disponibles a grandes rasgos.
- [ ] Elegir entre terminal e IDE según tu forma de trabajar.

> **Nota:** las extensiones e integraciones de IDE evolucionan; consulta [docs.claude.com](https://docs.claude.com) para las disponibles y sus pasos actuales.

## Prerrequisitos

- Lección 03 del módulo.

## Contexto

Claude Code nació en la terminal, pero buena parte del trabajo ocurre en el **editor**. Las integraciones con IDEs (como VS Code o los de JetBrains) acercan el agente a donde ya estás programando.

## Contenido principal

### 1. Qué cambia en el IDE

Integrado en el editor, Claude Code puede mostrar sus **cambios como diffs nativos** del IDE, entender qué archivo tienes abierto y encajar mejor en tu flujo visual. Para quien vive en el editor, es más cómodo que alternar con una terminal aparte.

### 2. Integraciones disponibles

Hay extensiones para los editores más usados (familia VS Code y familia JetBrains). La instalación suele ser desde el marketplace del editor; luego se conecta con tu sesión de Claude Code.

### 3. Terminal vs. IDE

- **Terminal:** ligera, scriptable, igual en cualquier máquina. Buena para sesiones rápidas y servidores.
- **IDE:** integración visual, diffs nativos, contexto del archivo abierto. Buena para trabajo sostenido de programación.

No es excluyente: muchos usan ambas según el momento.

## Ejercicio práctico

1. Si usas un IDE compatible, instala la integración de Claude Code.
2. Haz un cambio y observa cómo se muestran los diffs en el editor.
3. **Criterio de éxito:** sabes trabajar con Claude Code desde tu IDE y desde la terminal.

## Errores comunes

- **Asumir que cambia las capacidades:** el agente es el mismo; cambia la comodidad y la presentación.
- **No actualizar la extensión:** versiones desfasadas dan problemas de conexión.

## Resumen en 3 frases

1. Las integraciones de IDE acercan Claude Code a donde programas, con diffs nativos y contexto del archivo abierto.
2. Hay extensiones para los editores más comunes; la terminal sigue siendo válida y portable.
3. Terminal e IDE se complementan; elige según el tipo de sesión.
