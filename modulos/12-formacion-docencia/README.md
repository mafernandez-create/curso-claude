# Módulo 12 — Formación y docencia sobre Claude

**Eje:** Formador (opcional 🔹)
**Tiempo estimado:** 5–8 h
**Prerrequisitos:** Módulos 02 y 03. Idealmente también 05.
**Última actualización:** 2026-04-23

## Objetivo

Preparar a formadores, docentes y responsables de diseño instruccional para **enseñar** el uso de Claude a terceros (equipo, alumnado, clientes, familia). No se trata solo de saber usar Claude, sino de saber transmitir su uso de forma responsable, adaptada al contexto y con sentido crítico.
