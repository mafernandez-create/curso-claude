# Módulo 05 — Prompt Engineering avanzado

**Eje:** Transversal
**Tiempo estimado:** 8–10 h
**Prerrequisitos:** Módulo 02 (AI Fluency) y algo de Módulo 03
**Última actualización:** 2026-04-23

## Objetivo

Dominar las técnicas de prompting específicas de Claude: desde las buenas prácticas generales hasta las funciones más particulares del modelo (XML tags, prefill, extended thinking, caching). Este módulo es útil tanto si usas Claude vía interfaz como vía API.
