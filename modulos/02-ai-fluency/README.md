# Módulo 02 — AI Fluency: alfabetización IA

**Eje:** Base
**Tiempo estimado:** 5–7 h
**Prerrequisitos:** Módulo 01 (recomendado, no obligatorio)
**Última actualización:** 2026-04-23

## Objetivo

Desarrollar "alfabetización en IA": saber interactuar con sistemas como Claude de forma efectiva, eficiente, ética y segura. Es un módulo transversal cuyo contenido se apoyará directamente en el curso oficial de Anthropic *AI Fluency: Framework & Foundations*.
