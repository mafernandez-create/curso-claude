# Módulo 09 — Skills y Subagentes

**Eje:** Desarrollador
**Tiempo estimado:** 6–9 h
**Prerrequisitos:** Módulos 06 (Claude Code) y 05 (prompt engineering).
**Última actualización:** 2026-04-23

## Objetivo

Crear, empaquetar y distribuir Skills propias para Claude Code y Claude.ai. Entender cuándo usar subagentes y cómo orquestarlos para tareas complejas. Saber distinguir cuándo un problema necesita una Skill, un tool, un comando slash o simplemente un buen prompt.
