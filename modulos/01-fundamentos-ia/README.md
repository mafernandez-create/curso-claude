# Módulo 01 — Fundamentos de IA y LLMs

**Eje:** Base
**Tiempo estimado:** 8–10 h
**Prerrequisitos:** ninguno
**Última actualización:** 2026-05-08

## Objetivo

Entender qué es un Large Language Model, cómo se entrena Claude, qué lo distingue conceptualmente de otros modelos, y cuáles son sus limitaciones fundamentales. Sin esta base, todo lo que venga después se aprende "de memoria" y se desfasa rápido.
