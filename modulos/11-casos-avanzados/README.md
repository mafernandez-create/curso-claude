# Módulo 11 — Casos prácticos avanzados

**Eje:** Integración (opcional 🔹)
**Tiempo estimado:** 10–20 h (muy variable según profundidad)
**Prerrequisitos:** Módulos 07, 08 y 09.
**Última actualización:** 2026-04-23

## Objetivo

Aplicar todo lo aprendido a proyectos reales y complejos. Este módulo es más un **banco de proyectos** que un conjunto de lecciones lineales. La idea es que elijas 2–3 proyectos según tu interés y los llevés a cabo de principio a fin.
