# Módulo 04 — Productividad con Claude

**Eje:** Usuario
**Tiempo estimado:** 6–8 h

**Última actualización:** 2026-04-23

## Objetivo

Integrar Claude en tu flujo de trabajo diario de forma que te ahorre tiempo real y mejore la calidad de tus entregas. Foco en workflows prácticos y reutilizables, no en trucos aislados.

## Entrega

Construye y documenta 3 workflows propios:
1. Uno para **escritura** (redacción asistida, revisión, pulido).
2. Uno para **análisis de datos** (p. ej. Excel con Claude).
3. Uno para **revisión de documentos** (contratos, informes largos, PDFs).

Cada workflow debe tener: objetivo, prompt base, proceso paso a paso, y criterios de éxito.
