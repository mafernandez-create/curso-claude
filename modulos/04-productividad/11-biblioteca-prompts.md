# Construir una biblioteca personal de prompts

## Objetivos de aprendizaje

Al terminar esta lección serás capaz de:

- [ ] Explicar por qué merece la pena **guardar y organizar** tus mejores prompts.
- [ ] Estructurar una biblioteca de prompts sencilla y reutilizable.
- [ ] Mantenerla viva: mejorar los prompts con el uso.

## Prerrequisitos

- Lección 02 del módulo (workflows).

## Contexto

Cuando das con un prompt que funciona de maravilla, lo normal es… perderlo en el historial. Una **biblioteca de prompts** es tu colección personal de "recetas" probadas: las tienes a mano, las reutilizas y dejas de reinventar la rueda. Es la culminación práctica de este módulo.

## Contenido principal

### 1. Por qué una biblioteca

- **Ahorras tiempo:** copias un prompt probado en lugar de redactarlo de cero.
- **Ganas consistencia:** mismas tareas, misma calidad.
- **Acumulas conocimiento:** tu experiencia con Claude queda capturada, no se evapora.

### 2. Cómo estructurarla

No necesitas nada sofisticado. Un documento (o un Project de Claude) con, por cada prompt:
- **Nombre** y **para qué sirve.**
- **El prompt** (con huecos `[así]` para rellenar).
- **Notas de uso:** cuándo va bien, qué ajustar.

Agrúpalos por área (escritura, datos, reuniones…).

### 3. Mantenla viva

Cada vez que mejoras un prompt en una conversación, **vuélcalo** a la biblioteca. Borra los que ya no uses. En unas semanas tendrás un activo personal valioso. Conecta con los **workflows** de la lección 02: cada workflow tiene su prompt base, y ahí es donde vive.

## Ejemplo aplicado

Entrada de biblioteca:
```
Nombre: Resumen ejecutivo
Para qué: convertir un texto largo en un resumen de una página para dirección.
Prompt: "Resume el siguiente texto para un comité directivo: máximo
una página, con un titular, 3 puntos clave y una recomendación.
Texto: [pegar]"
Notas: si el texto es muy técnico, pedir además un glosario de 3 términos.
```

## Ejercicio práctico

1. Rescata de tu historial **tres prompts** que te hayan funcionado bien.
2. Guárdalos con nombre, prompt y notas.
3. Reutiliza uno esta semana.
4. **Criterio de éxito:** tienes una biblioteca inicial de 3 prompts y has reutilizado al menos uno.

## Errores comunes

- **No guardarlos:** el mejor prompt es inútil si no lo encuentras mañana.
- **Acumular sin podar:** una biblioteca con basura no se usa; mantenla limpia.

## Resumen en 3 frases

1. Una biblioteca de prompts captura tus mejores "recetas" para reutilizarlas y ganar consistencia.
2. Basta una estructura simple: nombre, para qué, el prompt con huecos y notas de uso.
3. Mantenla viva volcando mejoras y podando lo que ya no usas; es el hogar de tus workflows.
